# Kairox platform

A reusable B2B sales platform (CRM + channel automation + AI agents) by Kairox AI Tech. First client: **Arifa Packing & Packaging LLC (Arifaa Pack)**, Ajman, UAE (food packaging: aluminium and plastic containers, cutlery, custom-branded packaging).

**Status (16 Nov 2026):**
- The 5 Nov business flow (WP1–WP12) and the 11 Nov SRS / platform changes (WP13–WP29) are built and tested.
- **16 Nov v2 platform plan** (*Accounts & Server Plan v2*): one Namecheap dedicated server with Coolify instead of AWS; every field runs in a **paid** or **free** version chosen by env vars (`KX_PLATFORM_PLAN`, `docs/PLATFORM_MODES.md`); Telnyx calls, Stalwart email (via SES), Deepgram → faster-whisper, ElevenLabs → Piper, BGE-M3, SigNoz, R2; database tiers (`docs/DATABASE.md`). Work list WP-V2-01 … 14 in `docs/V1_CHANGE_PLAN.md`; progress in `docs/V1_PROGRESS.md`.
